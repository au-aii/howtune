# ADR-0008: OS ネイティブなダーク/ライト追従（セマンティックカラー + ブランド色固定）

- **ステータス**: 採用済み
- **決定日**: 2026-07-04
- **決定者**: Team 10（ハッカソン後の個人継続: au-aii）

## 背景

初期の HowTune iOS は背景を `Color.black`、文字を `.white` にハードコードした**ダーク固定**で、OS のライト/ダーク設定に一切追従していなかった。ライトモード端末では白地に白文字で読めない箇所（ロゴ・コメントカード等）も発生していた。

「ダークもライトも OS にネイティブ追従させたい」という要件に対し、**新しいライト用の色を一から作り込むか / iOS 標準のセマンティックカラーに寄せるか**、そして**ブランドの赤・グラデーションをどう扱うか**を決める必要があった。

## 検討した選択肢

| 選択肢                                                    | メリット                                                                  | デメリット                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **システムセマンティックカラー + ブランド色固定（採用）** | OS 追従が標準機構で自動。アセットを新規に作らない。工数が最小で崩れにくい | ブランド専用のライト色味の作り込みは将来対応（今は標準色に委ねる） |
| アセットカタログに light/dark colorset を全色ぶん自作     | ブランドに最適化した両モードの色を持てる                                  | 全色を二重定義・保守。工数大。ハッカソン速度に不向き               |
| ダーク固定のまま（現状維持）                              | 変更ゼロ                                                                  | ライト端末で可読性が破綻。「OS 追従」の要件を満たせない            |

## 決定

**汎用色は iOS 標準のセマンティックカラーへ置換して OS 追従させ、ブランド色（アクセント赤・グラデーション・HowTag 7色）は固定値のまま維持する**ハイブリッドにする。

- **汎用色の置換**（`HowTuneDesign` トークン中核 = `OnboardingComponents.swift`）:
  - 背景 `Color.black` → `Color(.systemBackground)`
  - 主要文字/アイコン `.white` → `Color(.label)`、副次 → `Color(.secondaryLabel)`、境界 → `Color(.separator)`、カード塗り → `Color(.secondarySystemBackground)`
- **ブランド色は不変**: アクセント赤 `Color(red:1.0,green:0.3,blue:0.3)`、`accentGradient`、`HowTag` の 7 色、**赤地/グラデ背景の上の白文字**はそのまま維持（両モードで正しい）。
- **テーマ制御**: `@AppStorage` の `prefersDarkTheme: Bool` を **`themePreference` enum（`system`/`light`/`dark`、デフォルト `system`）** に置換。`system` のとき `.preferredColorScheme(nil)` で OS 追従。ForYou のトグルは 3 状態循環（`circle.lefthalf.filled`/`sun.max.fill`/`moon.fill`）。
- **一括置換の進め方**: 54 ファイルを機能グループ G1〜G8 に分割し、ファイル非重複で **dev-agent を並列実行**（編集衝突なし）。置換ルール表＋置換禁止リストを共有して判断を揃える。

## 結果

- ライト/ダークとも OS 設定に自動追従し、白地白文字の可読性破綻を解消。ブランドの赤・グラデーションは両モードで一貫。
- 標準セマンティックカラーに委ねたため**新規アセットゼロ・軽量**で、将来ブランド専用のライト色味が必要になれば `HowTuneDesign` の参照先を colorset に差し替えるだけで拡張できる。
- `xcodebuild` グリーン、`simctl ui appearance light/dark` で主要画面のスクショ検証済み（OS 追従・ブランド色維持を確認）。PR #7 でマージ。
- 表示のみの変更で API・認証・データには影響しない。
